# Instruções do projeto

Mantenha os modos locais sem chamadas de rede. Não introduza credenciais, documentos privados ou resultados fictícios apresentados como medições reais. Teste alterações com `python -m unittest discover -s tests -v`. Preserve as limitações e os comandos documentados no README. Chamadas reais à API devem ser explícitas e usar credenciais do ambiente.
